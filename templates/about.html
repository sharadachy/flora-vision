🌸 About Floravision

Where Artificial Intelligence meets the beauty of nature

🌿 Our Mission

Floravision was created to simplify plant identification using deep learning and computer vision. Users can upload a flower image and instantly receive accurate species predictions powered by AI.

🤖 Technology Stack

Python

Backend processing and model integration

Flask

Web framework managing routes and templates

PyTorch

Deep learning framework powering the CNN model

HTML & CSS

Responsive and modern UI design

🧠 How the Model Works

The system uses a Convolutional Neural Network (CNN) to extract patterns such as textures, shapes, and edges from plant images. These features pass through multiple layers to generate accurate predictions with high confidence scores.
